# Kafka Lab v1.0.0

Kafkaの5用途を動くコードと構成図で学ぶ公開ラボです。
RisingWaveを中心に、ログ分析、推薦スコア、アラート判定、直接CDC、outboxによる移行を実装しました。

- Flink、Fluss、Materialize、Arroyo、Icebergの比較実装と自動検証。
- 日本語解説、構成図（Mermaid・SVG・PNG）、運用・復旧ガイド、学習演習、英語面接スクリプト。
- 25 unit tests、実データ照合、再起動・replay、DB commit後の失敗と再配送を検証。
- RisingWave起動引数・memory設定、Flinkのファイル権限、FlussのSQL実行モードを修正。

開始:

```bash
git clone https://github.com/hjosugi/kafka-lab.git
cd kafka-lab
bash scripts/lab.sh demo
bash scripts/lab.sh query
```

Docker Engine / Docker Desktop とCompose（v2以降）が必要です。Dockerなしでは `bash scripts/lab.sh test` が動きます。
配布物は `kafka-lab-v1.0.0.zip`、`kafka-lab-v1.0.0.tar.gz`、`SHA256SUMS` です。

ローカルサービスはPodmanの作業専用networkで検証し、標準Compose経路は
[GitHub Actions](https://github.com/hjosugi/kafka-lab/actions/workflows/ci.yml)で検証します。
[検証記録](https://github.com/hjosugi/kafka-lab/blob/main/docs/validation.md)に実行条件を記載しています。

小規模の学習用ラボとして、単一broker、例示用資格情報、有限fixtureを使います。
負荷試験・本番HA・完全な無停止移行は含みません。Iceberg例は有限データのlandingです。
元記事の画像・本文は同梱せず、独自のコード・図・データをMITで公開します。
