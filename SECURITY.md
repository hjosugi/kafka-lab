# Security

This is an educational local lab. Published container ports bind to loopback. Kafka uses PLAINTEXT,
one broker, and replication factor 1. PostgreSQL credentials are disposable examples.

For deployment considerations, read [operations](docs/operations.md). Do not expose the lab directly
to a public network or store real customer data in the fixtures.

To report a vulnerability, use GitHub's private vulnerability reporting when available. Avoid posting
credentials or exploit details in a public issue. No production support or security-response SLA is provided.
